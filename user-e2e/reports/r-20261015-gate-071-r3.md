## loop-rob I2 勘误段（探针侧，非产品面）

- **现象**：首轮 `harness all` R1-500-storm = `completed=false zeroContent=true I2=false`，
  而 0.1.70 面（gate-070）= `completed=true zeroContent=false I2=true`。
- **产品面定因 = 正确**（r3 500-storm session 实锤）：末位 stream-json result =
  `{"type":"result","subtype":"error_during_execution","is_error":true,"errors":["ModelPoolExhaustedError:
  All 1 model(s) in pool for role 'premium' failed:\n  - iff/Qwen38-27B-TXT: api_error_500\n
  Fix: Check provider credentials/quota, or switch to another provider/model…"]}` = **非静默
  显式错误**（可行动指引在场）= 场景注释预期面「任务不完成、**非静默**」满足。
- **0.1.70→0.1.71 面差异 = A-1 波体内预期行为变更（非回归）**：0.1.70 = raw 500 抛 →
  turnRecovery 恢复 → mock 40× 预算耗尽后「碰巧」完成（gate-070 completed=true，实际偏离
  场景「预期任务不完成」面）；0.1.71 = A-1 聚合 ModelPoolExhaustedError 显式终止（更贴
  场景预期面）。A-1 scope = chat/chatWithDelta 双路径聚合（500 = api_error 类在册，修波
  裁定留档维持双路径）。
- **harness I2 表达式 = 探针侧潜伏缺陷**：原式 `I2 = r.zeroContent ? false : (r.completed ||
  explicitError || r.killed)` 在 zeroContent=true 时无条件短路 false，吞掉 explicitError 面
  ——与自注语义「要么完成、要么显式 is_error（非静默）」矛盾。0.1.71 A-1 聚合新引入「任务
  未完成（zeroContent=true）+ 显式 is_error」面，500-storm 首次触发该潜伏假阴。
- **勘误（探针侧，零弱化）**：`I2 = explicitError || (r.zeroContent ? false : (r.completed ||
  r.killed))`——explicitError 在场即非静默（I2=true）；真静默丢弃面（zeroContent 且无显式
  错误且未完成）判定不变（I2=false）。附 `ATLAS_E2E_LOOPROB_SCENARIO` 单场景过滤器
  （缺省全场景，向后兼容）。
- **复验**：勘误后单场景 500-storm = `I1=true I2=true I3=true`（行为面与首轮一致：
  completed=false ms≈1680 tools=0 = 确定性）；**全量 all 重跑终值（looprob-r2.log，
  artifacts/all-1792014060398-b6x1）= 全场景 I1/I2/I3 全 true**：R1-nominal（completed
  tools=22）/ R1-500-transient（completed tools=8）/ R1-drop-transient（completed tools=8）/
  R1-empty-bounded（completed tools=7）/ R1-delay（completed tools=17）/ R1-500-storm
  （completed=false zeroContent=true **I2=true**〔勘误后非静默显式错误正确判定〕）/
  R3-resume（① SIGKILL@25000ms killed=true → ② --resume completed=true ALL TESTS PASSED
  实跑通过）。
