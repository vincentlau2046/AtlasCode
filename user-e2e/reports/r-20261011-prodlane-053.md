## 2. 定因登记区

### 根因①（**门禁**）：③ 重评消费支生产不可达 = 本波产品缺口 #2

**症状**（行为面 r3 @ 钉住源面 bun @worktree-prodlane-053）：
- stage2 `--resume`（stateB 缺 → 设计 = 重评 latest marker 再 defer，幂等 num_turns=0 零 LLM）→ 实际 **num_turns=1**（新 LLM 回合，模型自发重发 Write + newline），result subtype='deferred'（再挂起经 hook 对**新 tool_use** 裁定，非重评支）；A4_idempotent=false。
- stage3 `--resume`（stateA 在场 → 设计 = 重评 allow → executeToolUse → tool_result 追加）→ 实际新 LLM 回合重发 Write（第三次，call_7d98fefa…），执行成功但**经常路径非重评支**；最新 marker（call_f37d6c72…）的 tool_result 缺席（A5=false）；A6/A7/A8=true（TypeError 红面已修 + 任务完成）。
- session 文件 a0381bb1 时间线（10 行）：L2 assistant(Write call_d577…) → **L3 marker** → L4 assistant(stage2 新回合 Write call_f37d…) → **L5 marker** → L6 assistant(stage3 新回合 Write call_7d98…) → L7 tool_result(OK) → L8/L9 Read+result → L10 end_turn。两 marker 均悬空（各自 tool_use 无 tool_result），且 L4/L6 的 parentUuid 均跳过 marker 直挂父 assistant = marker 恒为孤儿 child。

**根因**（码面，钉住 @b76005e 读码）：
1. `loadTranscriptFile` 叶计算（`src/engine/session/load.ts`，loadTranscriptFile 尾部）：终端消息若为 system（marker）→ 跳过，回走到最近 user/assistant 祖先为叶（注释原文 = "Other message types (system, attachment) are metadata or auxiliary and shouldn't anchor a conversation chain"）。resume 时刻叶 = 挂起前最后 assistant tool_use 消息。
2. `buildConversationChain`（load.ts:317）：仅沿 `parentUuid` 从叶→根单向走链。marker 是叶的 **child**（写入时 parentUuid = 该 assistant uuid）→ 结构性排除。
3. `findDeferredToolUseState`（print.ts:639）仅扫传入 conversation（= 上述链）→ 恒无 marker → undefined → print.ts:1320-1334 重评支恒不触发。
- `isTranscriptMessage`（predicates.ts:29）含 system → marker **在** messages map（装载成功）；`processResumedConversation`（restore.ts:109）不变换消息（仅 session/pointer/元数据）→ 排除点唯一 = 叶计算 + 单向走链。
- **gate 漏因**：0.1.52 gate 判别单测直调 `findDeferredToolUseState`/`reEvaluateDeferredToolCalls`（人工构造会话，marker 在数组内）→ 单测全绿；生产装载路径（marker 经 leaf-anchored 链建）从未在 gate 面覆盖 → ③ 设计验收（零 LLM 幂等重评）在生产面不可达而 gate 无感。

**修方向候选**（e2e 不定设计，Main 裁定落码）：
- **A（装载面最小修，倾向）**：`loadResumedMessages`（或叶计算）对「未解决 deferred marker」特判 —— marker 的 parent 在链内且其后无该 tool_use 的 tool_result 时，marker 追加进 conversation（或作为叶锚定候选）；影响面 = 仅 headless `--resume` 挂起会话，正常会话零回归（无 marker 面零接触，零回归约束 3 保）。
