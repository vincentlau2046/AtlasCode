# 0.1.94 段 M lock-face（草稿）：makeCtx setAppState 缺陷修复（Main → f4）

> 依据：工单 §3 段 M + §6 审计吸收 4（lock-face 三点必答 + per-domain 读写单源归一表）。
> 状态：草稿——C-3 闭环后随 C-3 收尾报一并发出。

## A. 缺陷实锚（print.ts makeCtx L1122-1128）

```ts
const makeCtx = (): SdkToolUseContext => ({
  ...
  getAppState: () => ({ toolPermissionContext: tpcRef.current }),
  setAppState: updater => {
    tpcRef.current =
      updater({ toolPermissionContext: tpcRef.current }).toolPermissionContext
  },
})
```

双重 fail-silent（审计实锚复确认）：
1. updater 收到的 prev = `{toolPermissionContext}` 窄形——任何非 TPC 域读（如 TodoWrite 读 `prev.todos`）恒 undefined；
2. updater 返回的全态被回读只取 `.toolPermissionContext`——非 TPC 域写全部静默丢弃。

## B. SDK lane 越域写消费面枚举（落码前逐工具核）

| 工具族 | setAppState 写域 | SDK lane（-p）可达性 | 判定 |
|---|---|---|---|
| **TodoWrite**（todoWriteTool.ts:147 读 / :154 写 `todos`） | todos | **可达**（SDK lane 常驻工具） | **主体缺陷面**：读恒 undefined + 写静默丢弃（写后读不回实锤） |

| team 族（TeamCreate/Delete/SendMessage/WaitForTeammates） | teamContext 域 | isAgentSwarmsEnabled 门 OFF 不可达 | 登记级（门 ON 时同缺陷，随本修复覆盖） |

## C. 修复向（f4 预注册：窄视图职责单一化 + SessionContextPort）

setAppState 仅承 TPC 域写入（维持 tpcRef 单源不变）；越域写需求面经 SessionContextPort 注入。

### per-domain 读写单源归一表（SDK lane / headless -p）

| 域 | 读单源（修后） | 写单源（修后） | 修前态 |
|---|---|---|---|
| toolPermissionContext | tpcRef.current（makeCtx.getAppState + checkPermission gate 构建点，不变） | tpcRef（makeCtx.setAppState，不变） | 已单源，零变更 |
| todos | **port**（SessionContextPort.todosRef 活读） | **port**（TodoWrite 写点改道 port；port 缺席 = fail-visible throw） | 读=窄形缺域 / 写=静默丢弃（双缺陷） |
| tasks | engine task 域 services（updateTask/claimTask，工具不经 setAppState） | 同左 | 已单源，零变更 |
| teamContext | team services 门 OFF 不可达 | port 同 todos 面（门 ON 时生效） | 登记级 |

### 三点必答预答

1. **RED→GREEN**：RED = SDK lane TodoWrite 写后读不回（判别格：makeCtx 下 TodoWrite.call 写 todos → 再 call 读 oldTodos 恒 [] / 写值不可观测）→ GREEN = port 落点可观测（判别格：port 注入后写值在 port 载体可读回，TodoWrite oldTodos 回读正确）。
2. **TPC 域权限门零回归格**：判别格断言 makeCtx TPC 面（plan 族 setAppState / checkPermission gate tpcRef 活读）修前修后行为恒等；canon 全量绿兜底。
3. **port 缺席写失败 fail-visible**：TodoWrite 写点 port 缺席（headless 未注入 port 的异常构形）= 显式 throw（错误信息含落点指引），禁新静默换旧静默。
