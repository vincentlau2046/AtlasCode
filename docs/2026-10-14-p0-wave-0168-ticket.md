### F-1′ · 恢复对齐（对齐 Claude autocompact 恢复设计 = 富路径恢复组件补全，~3–6 文件）

**根因（@d4b492d 锚定）**：REPL 主 loop 的 auto-compact 走**裁剪版** `compactConversation`（`agentLoopDeps.ts:147-175` 注入体 `compactConversation(msgs, { summarize, countTokens, keepRecent: 0 })`）：`keepRecent: 0`（`compact.ts:516-518` 缺省 0 = 全量压缩，`messagesToKeep` = undefined）+ **`attachments: []` / `hookResults: []` 硬置空**（`compact.ts:537-543` D-2a S2「裁剪 producer 置空数组」登记 stub）→ **post-compact 上下文 = [boundaryMarker, …summaryMessages] 仅此** → 模型失全部文件态/工具近态，必须重读 = 「重新 session 凭记忆重新读取」直接机制。富路径 `richCompactConversation`（`compact.ts:577`，`L723 p.buildPostCompactAttachments` + `L787 reAppendSessionMetadata`）**仅** 手动 `/compact` + reactive 支消费，proactive auto-compact 不消费。

**修复目标（行为面）**：auto-compact 后上下文含 ① **近期消息保留**（`keepRecent N`，N 为 Main 定参，参考富路径 keepRecent 语义）② **文件/工具附件重注**（`buildPostCompactAttachments`）→ 模型不必重读文件 = 恢复质量对齐上游。

**落码面（@d4b492d 锚定）**：
- `agentLoopDeps.ts:147-175` autoCompact.compact 注入体：现 = 裁剪 `compactConversation(msgs, {summarize, countTokens, keepRecent:0})` → 改消费**富路径** `richCompactConversation`（经 `CompactPorts` DI 缝）或**最小子集**（`keepRecent N` + `buildPostCompactAttachments` 重注，hooks 可不启用 = 更窄变更面）。
- 富路径需 `CompactContext`（`getAppState`/`toolUseContext`）= loop materials 可构造；`CompactPorts` 已注册（`contextHostWiring.ts:166 setCompactPorts`：`summarize`/`executePreCompactHooks`/`executePostCompactHooks`/`processSessionStartHooks`/`buildPostCompactAttachments=composePostCompactAttachments`/`markPostCompaction`/`notifyCompaction`）→ **engine React-free 红线不破**（LLM-bound/文件 IO 叶全走 port DI）。
- **Main 定项**：① 全富路径 vs 最小子集（成本 = 摘要调用 + 文件 IO + GB cache-prefix 影响）② `keepRecent N` 值 ③ PreCompact/PostCompact hooks 是否启用（auto-compact 面或仅附件重注、hooks 保持关 = 更小变更面）。

### F-3a · 小窗阈值非正守卫（~1–2 文件）

**根因**：`autoCompact.ts:289` 阈值 = `getEffectiveContextWindowSize(窗口) − AUTOCOMPACT_BUFFER_TOKENS(13_000)` **无正数 clamp**：`getEffectiveContextWindowSize` = 窗口 − min(maxOutput??20k, 20k) → **32K 窗模型 = 有效 12K → 阈值 −1K** → `shouldAutoCompact` 恒真（tokens > −1K 恒真）= **每轮触发压缩风暴**（每轮一次 LLM 摘要 + 已摘要上下文再摘要 = 信息流失 + 极慢）+ TokenWarning UI 阈值（`autoCompact.ts:430-434` `threshold − WARNING/ERROR_BUFFER`）同负失守。

**修复目标（行为面）**：阈值 ≤ 0 → **auto-compact 禁用 + 显形**（UI 提示「窗口过小，auto-compact 已禁用；建议手动 /compact 或换小上下文模型」）+ TokenWarning UI 同面守卫（负阈值不假警告）。

**落码面**：`autoCompact.ts:289-296`（阈值核，加正数 clamp / 非正禁用支）+ `L424-434`（UI 阈值派生面同守卫）。

**判别单测**：32K 窗模型阈值面（修前 −1K 红→修后 禁用/clamp 绿）+ **大窗模型阈值精确同值恒等锚**（256K/1M 模型阈值 = 修前精确同值，零回归）。
