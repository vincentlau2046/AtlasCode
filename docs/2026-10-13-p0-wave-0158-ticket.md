### C4-1 · mid-stream 部分保留细目
- **现状锚定（f4 D1 已核 @0.1.57 8021d80）**：流中途错误时已收 partial 处理面 = **∅**（PAC V2-06 D1「mid-stream ∅」；modelprovider 错误分类面在场〔`errorUtils.ts` extractConnectionErrorDetails + `errorMessaging.ts`〕，但 partial 保留/续接消费点未建；候选消费面 = `src/engine/query/turnRecovery.ts`）。
- **落码**：流式响应在已产出部分内容后遭遇错误 → partial 内容保留为 assistant 轮次内容（标记 interrupted/partial 语义，Main 裁定标记面），后续错误处理走既有错误面（不裸抛吞内容）。**语义 = CC 2.1.199「保留已收 partial」**：模型看到的上下文不丢已完成段，重试/续接基于 partial 而非从头。
- **边界**：零 partial（错误发生在首 token 前）= 现有行为恒等（走既有重试/错误面，不进 partial 保留支）。

### C4-2 · ECONNRESET 退避细目
- **现状锚定（f4 D1 已核）**：ECONNRESET errno 判定**已在场**（`modelprovider.ts:181` 瞬断类正则 + `error.cause.code` 覆盖〔#4 盲区已修〕）；`maxRetriesPerModel=3`（L287）+ 重试循环（L366）**固定间隔无退避** → 增量面。
- **落码**：重试循环对瞬断类错误（ECONNRESET/ECONNREFUSED/socket hang up 族，既有 `isRetryableError` 分类面）加**指数退避**（base × 2^attempt，封顶，具体值 Main 裁量——建议 base 500ms / cap 8s 量级，避免会话挂起感）；非瞬断类错误（4xx 认证/参数类）**零退避**（既有行为恒等）。重试次数（3）与分类面**不变**（仅增量退避，不扩 scope）。
- **可测性**：退避时序 = 判别断言面（attempt 间隔单调递增 + cap；零 partial/非瞬断面零退避）。
