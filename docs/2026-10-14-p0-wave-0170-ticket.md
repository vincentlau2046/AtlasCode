### G-1 · modelProvider.chat 增 onStreamDelta 回调槽（~1–2 文件）

**根因（@0.1.69 锚定）**：`modelProvider.chat`（`modelprovider.ts:377-497`）= `Promise<{完整 message}>`，内部 for-await stream 循环（L744-794）逐 token 累积 `fullText`，**delta 不外泄**。签名无 `onStreamDelta` 槽 → 调用方（queryOneRound）无法订阅 per-token。

**修复目标（行为面）**：`chat()` 签面增 `onStreamDelta?: (delta: StreamDelta) => void`（chatArgs 传入）；chat 内部 for-await 每个 delta（text_delta / tool_use_start / tool_use_delta / tool_use_end）调 `onStreamDelta?.(delta)`。未传 = 零行为（headless/测试面恒等）。

**落码面（@0.1.69 锚定）**：
- `modelprovider.ts:377` chat 签面增 `onStreamDelta?: (delta: StreamDelta) => void`（StreamDelta = modelprovider 已有 StreamEvent 子集，复用 `types.ts`）。
- `modelprovider.ts:497` chat 实现内部 for-await（L744-794）每个 `yield {type:'text_delta',...}` / `yield {type:'tool_use_start'...}` 等同步调 `args.onStreamDelta?.({type:'text_delta', text})`（或经统一 StreamDelta 投影）。
- **Main 定项**：① StreamDelta 槽形 = 裸 StreamEvent 子集（`{type:'text_delta',text}` 等）vs 收窄投影型（仅 text/tool 两类）② onStreamDelta 调用时序 = 同步（yield 前/后，不阻塞流）③ reasoning_content/thinking delta 是否入 onStreamDelta（对齐 messages.ts thinking_delta 分支已有 onUpdateLength 调用）。

### G-2 · queryOneRound 透传 emit + AgentLoopEvent 增 stream_delta 型（~2 文件）

**根因（@0.1.69 锚定）**：`queryOneRound`（`loop.ts:416-449`）调 `deps.modelProvider.chat(chatArgs)` 返回完整 resp，**不订阅 per-token**。`AgentLoopEvent`（`loop.ts:154-178`）联合体无 stream_delta 型 → emit 无法载 per-token。

**修复目标（行为面）**：queryOneRound chatArgs 增 `onStreamDelta: (delta) => deps.emit?.({type:'stream_delta', delta})`（emit 同步观察者契约不变：适配器入队不抛）；`AgentLoopEvent` 增 `| { type: 'stream_delta'; delta: StreamDelta }`。

**落码面（@0.1.69 锚定）**：
- `loop.ts:426-443` chatArgs 增 `onStreamDelta: deps.emit ? (delta) => deps.emit!({type:'stream_delta', delta}) : undefined`（emit 未注入 = onStreamDelta 不传 = chat 零行为恒等锚）。
- `loop.ts:154` AgentLoopEvent 联合体增 `| { type: 'stream_delta'; delta: StreamDelta }`。
- **Main 定项**：① onStreamDelta 透传守卫（`deps.emit ? ... : undefined` 确保 emit 未注入面零回调开销）② stream_delta 是否入 transcript record（否——per-token 是瞬态进度，不入持久化 transcript，round_end assistantMessage 仍是唯一持久化面）。

### G-3 · loopEvents.ts 转发 stream_delta（~1 文件）

**根因（@0.1.69 锚定）**：`queryEngineLoopStream`（`loopEvents.ts:73-80`）emit 回调**只处理 `round_end`/`compacted`**，stream_delta 落 else 被丢弃 → TUI 永不收 per-token。

**修复目标（行为面）**：emit 回调增 `else if (event.type === 'stream_delta') { pending.push(...) }`；`EngineLoopStreamEvent` 联合体扩 `| { type: 'stream_delta'; delta: StreamDelta }`（或包装为 stream_event Message 形，见 Main 定项）。

**落码面（@0.1.69 锚定）**：
- `loopEvents.ts:40` `EngineLoopStreamEvent` 扩型：`| { type: 'stream_request_start' } | { type: 'stream_delta'; delta: StreamDelta } | Message`（直接扩型，不包装 Message = 消费侧 switch 更清晰）。
