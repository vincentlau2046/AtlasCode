### 1.1 AD-21 — EnterWorktree `path` 参数（CC 2.1.105，C-1 首件）

- **缺口定位（PAC 卡 D2）**：`engine/tools/worktree/worktreeToolInput.ts:13 EnterWorktreeToolInput = { name?: string }` = **无 path 参数（缺口坐实）**；复用原语在场 = `worktree.ts:795` fast-resume 复用支（getOrCreateWorktree/performPostCreationSetup 不触碰原 worktree）+ `worktree/git.ts` 校验面。
- **改法（1 件）**：入参 schema 加 `path?: string` + 现存 worktree 探测（`git worktree list`）+ 校验（路径存在且为本仓 worktree → 进入不新建；不存在/非 worktree → 可操作报错/拒）。
- **零回归约束**：仅 `name` 入参路径与现逐字恒等。
- **判别单测**：① path 指向现存 worktree → 进入（不新建）② 路径不存在 → 可操作报错 ③ 非 worktree 路径 → 拒（①② **修前红**：现无 path 入参，面不存在 → 判别面缺席）。
