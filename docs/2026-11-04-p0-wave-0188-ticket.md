3. **napi 二进制特例**：modifiers-napi/url-handler-napi/audio-capture-napi/image-processor-napi(+sharp) 为平台二进制——optionalDependencies 下 npm 装失败仍 rc0，须配 fail-visible 探针（对应功能路径显式降级，不静默）；084 Gap B（PDF 页图）在本波的核销口径 = sharp/image-processor-napi 声明后 fresh-install 该功能路径直证，不是只改 manifest。
4. **cli-highlight 常径风险**：§0 实核 require 面 = Ansi.tsx/color-diff（渲染常径）——若缺包，高亮功能面崩或降级？此项可能是「undici 后第二个常径成员」，处置优先级最高，探针须覆盖 ctrl+o/代码块渲染轮。
5. **死面甄别**：external 列表若有零 require 面项（锁面复核），处置 = 移除 external（收窄 build 面）而非声明；移除须 build 字节 diff = 0 验证，**双向语义：diff≠0 即证存在隐藏 require 面 = 移除不成立须回退重评**；死面移除即便 diff=0 亦属构建契约面变更，token manifest 备注登记。
6. **optional 三细分**：装失败（absent）≠ 装成 load 败（ABI/platform mismatch）≠ sharp 装成但其 prebuilt 二进制链缺（sharp 自身 optionalDeps）——fail-visible 探针至少覆盖 absent + load 败两支，或工单批注明示 absent-only 口径；平台特异项（@ant/computer-use-* 等 macOS 面候选）建议 os/cpu 字段收窄（防 Linux 服务器反复试装噪音）。
7. **optional 降级呈现形态逐项标注**（UI/log/文档；npm 对 optional 失败静默，用户不知为何降级——本波最低须 log 面）。
