### PR 1 — 慢模型流式显示对齐（Atlas `Beboppin 3m` → 对齐 Claude `Beboppin'… (1h 4m 23s · ↓ 2.5k tokens)`）

**主诉**：慢模型 TTFT（首 token 延迟，可达 10s–2min）期间，Atlas 只显"动词 + 计时"（如 `Beboppin 3m`），用户无法判断模型是否已开始流式输出；Claude 显"动词'… + 计时 + ↓ token 计数"，流式进度可见。

**根因（双缺口，f4 已定位 @ master c6c947d）**：

| # | 缺口 | 根因定位 | 机制 |
|---|------|---------|------|
| **G1** | TTFT 期间无流式状态指示 | `src/tui/components/Spinner/SpinnerAnimationRow.tsx:212-214` | `SpinnerModeGlyph`（↓/↑ 字形）**仅渲染在 `showTokens` 分支内**。`showTokens = wantsTokens(5s 门) && totalTokens > 0 && 空间`（`:197`）。首 token 前 `responseLengthRef.current = 0` → `totalTokens = 0` → `showTokens = false` → **无 ↓/↑ 字形、无 token 计数**。TTFT 期间用户只见"动词 + 计时"。 |
| **G2** | TTFT 期间误触 stall 红 | `src/tui/components/Spinner/useStalledAnimation.ts:44-46` | `isStalled = timeSinceLastToken > 3000 && !hasActiveTools`；`currentResponseLength === 0` 时 `timeSinceLastToken = time - mountTime`（从挂载计时）。**TTFT > 3s 即 spinner 渐变红**（`stalledIntensity` 2s 内 0→1），强化"卡死"错觉。 |

**流式状态机已存在但未用于显示**（`src/tui/utils/messages.ts:3000-3033`）：`stream_request_start` → mode `'requesting'`（请求已发，等首 token）/ `content_block_start`(text) → mode `'responding'`（流式开始）/ `SpinnerModeGlyph` 已区分 `requesting`→↑(arrowUp) / `responding`→↓(arrowDown)。**mode 转换信号齐全，但 ↑/↓ 字形被锁在 `showTokens` 门后，TTFT 期间不显形**。

**方案（对齐 Claude，3 子件）**：

| 子件 | 落码面 | 行为 |
|------|--------|------|
| **G1-fix · TTFT 期间显形流式状态指示** | `SpinnerAnimationRow.tsx` parts 构造（`:208-219`）+ showTokens 门逻辑（`:197`） | `showTokens = false` 但 `mode === 'requesting'` 且 `wantsTimer`（已过 1s 门）时，渲染轻量状态标记（↑ 字形或"等待响应"语义），让用户知道"请求已发出，正在等模型开口"（对齐 Claude `Beboppin'…` 省略号语义）。首 token 后（`mode='responding'` + `totalTokens > 0`）切 ↓ + token 计数（既有 showTokens 分支不变）。 |
| **G2-fix · TTFT 期间抑制 stall 红** | `useStalledAnimation.ts:44-46` | `isStalled` 条件增 `currentResponseLength > 0` 守卫：`isStalled = timeSinceLastToken > 3000 && !hasActiveTools && currentResponseLength > 0`。TTFT 期间（未收到任何 token）不报 stall；stall 仅在"已开始流式后中断 > 3s"触发（原语义保留）。 |
| **G3 · 动词省略号（可选，对齐 Claude 视觉）** | `SpinnerAnimationRow.tsx` / `GlimmerMessage.tsx` message 渲染 | `mode === 'requesting'` 时动词尾附 `…`（如 `Beboppin'…`），对齐 Claude 视觉。**Main 裁定纳入与否**（纯视觉面，零行为影响）。 |

### PR 2 — 慢模型超时错误上报去 IFF 硬编码

**主诉**：其他机器（未配置 IFF 网关 `127.0.0.1:8999`）慢模型超时/连接失败时，显示 `IFF 不可达：已切人工确认 —— /doctor 排查`。IFF 是本机本地网关别名，非 Atlas 特定网关 — 应上报实际模型/端点/厂家，而非 IFF。

**根因（硬编码字面量，f4 已定位 @ master c6c947d）**：

| 缺口 | 根因定位 | 机制 |
|------|---------|------|
| **硬编码 "IFF"** | `src/modelprovider/modelprovider.ts:187` | `gatewayUnreachableRemediationHint()` 检测连接失败族错误（SDK `APIConnectionError` / 网络 errno `ECONNREFUSED\|ENOTFOUND\|EHOSTUNREACH\|...`，`:178-184`）后，**return 固定串 `'IFF 不可达：已切人工确认 —— /doctor 排查'`**。其他机器用别的 provider/端点时仍报 IFF = 误导。 |

**消费链**：`REPL.tsx:2722` 调 `gatewayUnreachableRemediationHint(error)` → `:2723` 拼进 `createSystemMessage(...${gwHint}...请重试。, 'error')`，错误行直显用户。

**方案（去 IFF 化，参数化端点 label）**：

| 子件 | 落码面 | 行为 |
|------|--------|------|
| **P2-1 · 签名加 endpointLabel** | `modelprovider.ts:157` `gatewayUnreachableRemediationHint(error, endpointLabel?: string)` | 纯函数接收可选 `endpointLabel`（对齐 `llmTimeoutRemediationHint(error, currentTimeoutMs?)` 姊妹模式 — 纯函数 + 调用方传参）。 |
| **P2-2 · 错误串用实际端点** | `modelprovider.ts:187` 返回串 | `return \`${endpointLabel ?? 'LLM 端点'} 不可达：已切人工确认 —— /doctor 排查\``（如 `api.deepseek.com 不可达` / `本地网关 不可达` / `自定义端点 不可达`）。IFF 字面量移除。 |
| **P2-3 · modelprovider 域加 getCurrentEndpointLabel()** | `modelprovider/index.ts`（仿 `getCurrentLlmTimeoutMs()` 模式，`:58`）+ settings source 注册 | 纯读函数：读 endpoint config source（`resolveModel(mainLoopModel)` 或 `getRoleModels('premium')` 的 `baseURL`）→ `new URL(baseURL).host` 抽主机名 → fallback `'LLM 端点'`。**REPL catch 块调它传参**（`:2722`）。 |
| **P2-4 · REPL 传参** | `REPL.tsx:2722` | `const endpointLabel = getCurrentEndpointLabel(); const gwHint = gatewayUnreachableRemediationHint(error, endpointLabel);` |
| **P2-5 · re-export 跟进** | `modelprovider/index.ts:151` | re-export `getCurrentEndpointLabel`（REPL import 跟进）。 |

**超时路径无需改**：`llmTimeoutRemediationHint`（`:135-145`）报"LLM 请求超时"（generic，无 IFF）— 仅 `gatewayUnreachableRemediationHint` 连接失败族需去 IFF 化。

### PR1 製定

**G2 stall 守卫 — 抽纯函数 `computeStallState`**（落 `spinnerGates.ts`，判别单测面）：
```ts
export function computeStallState(
  timeSinceLastToken: number,
  currentResponseLength: number,
  hasActiveTools: boolean,
): { isStalled: boolean; stalledIntensity: number } {
  const isStalled = timeSinceLastToken > 3000 && !hasActiveTools && currentResponseLength > 0
  const stalledIntensity = isStalled
    ? Math.min((timeSinceLastToken - 3000) / 2000, 1)
    : 0
  return { isStalled, stalledIntensity }
}
```
