## B. 换道面与影响面

换道 = `tui/utils/swarm/backends/InProcessBackend.ts:13` 的 `startInProcessTeammate` import 从 T 副本改指 E 副本。

- **影响面 1（组合根缝，换道前置必答）**：TUI 组合根 = `tui/factory.ts:160 createCoreDependencies`（main.tsx:839 消费），**不跑 atlascode/compose.ts** → swarm 注入窗在 TUI 进程全未接线（grep 实证：`setTeammateToolRegistryDeps` / `setStartInProcessTeammate` 在 tui/factory.ts / main.tsx / bootstrapState.ts 零命中）：

  - E runner 内 `getTeammateToolRegistryDeps()` 窗未设 → fail-soft 零 deps 最小池 = TUI lane 成员工具池缩水（登记面）。
  - **提议**：TUI InProcessBackend 直 import engine 门面 `startInProcessTeammate`（不经 port，与 engine backends 副本 lane 内消费形互不干扰）+ `tui/factory.ts` 补 `setTeammateToolRegistryDeps` 接线（与 compose.ts:361 同形全量 toolRegistryDeps）。
