## 0. 安全面定位（f4 定案）

**信任单元**：per-server `oauth` 块（`clientId` / `clientSecret` / `callbackPort` / `authServerMetadataUrl` / `clientMetadataUrl`，types.ts:43 McpOAuthConfigSchema）= **一个信任单元**（单字段门控 = 半门控假安全面，0.1.74 4th-review 已裁拒）。

**威胁面**：oauth 块可来自 **untrusted scope**（project = repo `.mcp.json` 提交值 / plugin 提供 server）= repo/插件作者可控；用户批准项目级 MCP server 时一并批准的既有信任面 → **块级门禁**：untrusted scope 的 oauth 块默认不生效，须**显式 allowlist（操作者 pin）**方生效。

**scope 裁定（f4 定案）**：
- **untrusted = `project` + `plugin`** scope（repo 提交值 / 插件提供，非操作者直管）。
- **trusted = `user` / `local`（操作者机器级配置）+ `enterprise`（managed）+ env 部署控制**（操作者面）→ 恒通过（既有行为零变更恒等锚）。
