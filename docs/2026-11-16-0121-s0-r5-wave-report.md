## 2. 判据钉核销

- **钉 1（3-way）**：分类三臂各一腿直证（腿 2/7b = prefix 异；腿 6/7a = 自愈；腿 4 = 真损坏）。
- **钉 2（触发面唯一）**：oversize 仍走既有 resourceLimit（:458/:431 未动）；重采样仅由 unparseable complete record 触发。
- **钉 3（成本上界）**：重采样 stat 尺寸检查先行（> maxTranscriptBytes → resourceLimit——腿 8，禁 corruptData 冒名）；随 FollowLimits 加性 maxTranscriptBytes 传递（与 adapter readTranscript 同源同界）。
- **真损坏判据自证**：engine loader parseJSONL 静默跳过残行（json.ts:60+），不能作 corrupt 证据——重采样严格逐行 JSON.parse 自证（'unparseable complete record (resample confirmed)'），腿 4 断言 message 含 'resample' 锁形。
- **假阴残余**：rewrite 产合法 JSONL 且恰好 offset 对齐可解析 → 静默错流不设防（§2 终裁登记不叠加，候消费侧实测反弹再议）。

1. **cli.js 锚变更预记披露**（呈批书 §13 附加义务兑现）：follow/readonlyRuntime/cursorLedger 均 CLI 图内 → cli.js 字节数必然变更，段 L SRI 对表按新值披露（Δ 值随 build 落盘）。

3. **web 桥映射面（S3）**：runtime FollowSessionRequest 扩 resumeCursor 后经 entry.ts 纯 re-export 面自动流转（FollowSessionRequest 类型已出口）；pack build 全绿（85.20 KB bundle + 57 d.ts rewrite）；webSessionV0 契约 schema 零触碰（:87 resumeCursor optional 既有形——本波即其 runtime 兑现）。
4. **cursorTtlMs 硬下界**：expired 腿受 limits.ts HARD_MIN_CURSOR_TTL_MS=1000ms 约束（测试用 1000ms+sleep 1100ms；40ms 初值 invalidRequest 被拒——限制面自身行为，非本波改动）。
5. **protocol requestId 形**：FollowSessionRequestSchema.requestId = UUID 形（非 OpaqueId 任意串），测试已按 schema 实形校准。
6. **binding cast 收窄**：binding.generation/baselineId（string）→ 随机 UUID 模板字面量类型 cast——账本只发行 crypto.randomUUID() 形，运行面恒等。
