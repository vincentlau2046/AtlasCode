安装

一行 npm，即装即用

前置要求：Node ≥ 20

npm install -g @atlasharness/atlascode

atlas        # 启动交互式 TUI（atlascode 命令同效）
atlas --help # 查看全部选项

装完命令不识别 → 重开终端，或把 npm 全局 bin 目录加入 PATH。 配置文件：~/.atlas/settings.json（模型池与 Provider 设置）。
